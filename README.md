# Aplikasi POS & Akuntansi Toko

## Deskripsi
Aplikasi POS & Akuntansi Toko adalah aplikasi berbasis web yang digunakan untuk membantu mengelola kegiatan toko, seperti data barang, supplier, pembelian, penjualan, laporan, dan keuangan.

## Fitur
- Login pengguna
- Dashboard
- Data Barang
- Data Supplier
- Pembelian
- Penjualan
- Laporan
- Keuangan
- Logout

## Teknologi
- PHP
- MySQL
- HTML
- CSS
- XAMPP
- phpMyAdmin

## Cara Menjalankan
1. Install XAMPP.
2. Jalankan Apache dan MySQL.
3. Letakkan folder aplikasi di dalam `htdocs`.
4. Buat database `pos_akuntansi` melalui phpMyAdmin.
5. Import file `database/pos_akuntansi.sql`.
6. Sesuaikan konfigurasi database pada folder `config`.
7. Buka aplikasi melalui browser.
